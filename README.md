# 📚 StudyBuddy – Dein smarter Lernplaner

**StudyBuddy** ist eine moderne Web-App zur Planung und Organisation von Lernzielen, Lerneinheiten und Fortschritt – speziell für Schüler, Studierende und autodidaktische Lernende. Die App ist mit **ASP.NET Core (Razor Pages)** und **C#** entwickelt und demonstriert die Umsetzung von Fullstack-Webentwicklung auf Basis moderner .NET-Technologie.

---

## 🚀 Features (geplant / im Aufbau)

- ✅ Benutzeroberfläche mit Razor Pages
- ✅ Datenmodell für Lernfächer, Lerneinheiten und Ziele
- 🟡 CRUD für Fächer und Lernziele
- 🟡 Automatische Wochenplan-Erstellung
- 🟡 Erinnerungs-Logik für anstehende Lerneinheiten
- 🟡 Fortschrittsanzeige (z. B. Balkendiagramm)
- 🟡 Authentifizierung für mehrere Benutzer (optional)
- 🟡 Deployment auf Render oder Azure (coming soon)
